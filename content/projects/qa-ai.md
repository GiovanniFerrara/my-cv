- [GitHub](https://github.com/GiovanniFerrara/qa-ai-tester) - Autonomous QA agent using LLMs with Playwright integration to test web applications without predefined scripts.
- Uses ReAct pattern for reasoning and autonomous tool use. Identifies visual, functional, and accessibility issues.
- Generates structured reports with screenshots and actionable remediation hints for each discovered issue.
